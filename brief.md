# Pagewell - Source Brief

## Title
Pagewell

## Description
Pagewell is a reading and listening app for a digital publisher: ebooks with a calm EPUB reader, audiobooks that stream, a searchable reference library, a fresh editorial piece every day, bookmarks and favourites, and free and Premium membership. Editors schedule and publish new content from an in-app studio and readers see it on their next sync.

## Store links
Not yet published (portfolio POC).

## Platform
Android demo, iOS-ready codebase (Flutter).

## Category
Books and Reference / Media

## Features
- Ebook library (ebooks and audiobooks) with format and progress filters, and an empty state for new accounts
- EPUB reader that parses a real `.epub` (container, OPF, spine, XHTML): chapters, text size, light/sepia/dark themes, page bookmarks, progress
- Audiobook streaming player: buffer ahead of playback, 15 second skip, speed, sleep timer, chapters, audio bookmarks, mini player
- Search across book metadata, EPUB text, articles and the reference library, with scope chips and highlights
- Reference library entries with related terms and "appears in" books
- Daily editorial article on Today, driven by the CMS feed
- Accounts (sign in, guest mode), bookmarks and favourites
- Free and Premium membership with gated titles and reference entries, paywall with monthly and annual plans and a free trial
- Editor studio (content management): schedule with draft/scheduled/published status and publish-now

## Tech stack
- Flutter 3.35, Dart 3.9, Riverpod 3 (Notifier, AsyncNotifier)
- `archive` + `xml` for EPUB parsing
- Bundled Outfit and Fraunces fonts
- Unit and widget tests (`flutter test`), integration tests for capture (`integration_test`, `flutter drive`)
- GitHub Actions Android emulator capture
- Stack choice: the brief accepts Flutter or React Native and leaves the choice open, so the owner's default stack (Flutter + Riverpod) was used; it also gives one codebase for iOS and Android with full control of reader typography.

## Research notes
- Verified: EPUB parsing runs on a real EPUB 3 file generated by `tool/make_epub.py`; search covers the parsed book text; the CMS feed is a JSON document read at runtime and publishing updates Today. All covered by unit and widget tests.
- Mocked: authentication, purchases, the content API and audio transport. The streaming engine simulates a progressive download; production would use `just_audio` (HLS or MP3 over HTTPS) with background playback and lock-screen controls.
- Design QA (Android capture): 99/100, no Critical or Major. Open Minor: "Listen to this article" shows a message instead of opening narrated audio.
- Next steps: connect a headless CMS (Strapi, Sanity or Firebase) for books, articles and reference entries; EPUB rendering for images, CSS and footnotes (or a package such as `epub_view` / Readium); DRM or signed URLs for premium files; offline downloads; StoreKit and Play Billing through RevenueCat; analytics; a web admin for editors beyond the in-app studio.
